# Stack, keys, and what's missing

## What the site runs on

| Layer | Choice | Why this one |
|---|---|---|
| Build | **Vite 6 + TypeScript** | Plain files you own; `npm run build` produces static HTML/JS; Vercel detects it with zero config. |
| 3D | **Three.js r170** | The concept page was already Three.js; nothing here needs a framework on top of it. |
| Scroll | **Lenis** (smooth scroll) + **GSAP ScrollTrigger** (scroll → progress) | The pair the reference prompt names; both free; both standard. ScrollTrigger drives the camera rig's progress, Lenis makes wheel steps feel like a dolly. |
| Plan drawing | **Plain SVG, generated by `src/plan/npr.js`** | No library. The same module runs in the browser page and in the Node CLI. |
| Data | **`floorplan.json`** + **`brand.json`** | One file per property, one file for her facts. Schema-validated. |
| Hosting | **Vercel** (hobby, team `nymfarious-projects`) | Free for this; GitHub integration deploys every push to `main` and every PR to a preview URL. |
| Fonts | Google Fonts (Bodoni Moda, Karla, Mrs Saint Delafield; Caveat/Fraunces/Public Sans on the plan page) | Self-host before the in-person demo — see site-spec M1 checklist. |

Node ≥ 20 (`.nvmrc` says 22). `npm install`, `npm run dev`, `npm run build`, `npm run plan <file>`.

## Cesium ion asset 1 — the answer to your question

**What it is.** Asset ID 1 on Cesium ion is *Cesium World Terrain*: a global, high-resolution elevation mesh (quantized-mesh tiles), assembled from many public terrain sources, streamed from Cesium's CDN. It has no imagery and no buildings — it is the ground's shape. It's included on every ion plan including the free one, and it's the terrain every CesiumJS demo you've seen uses.

**Is it reliable?** Yes. It has been the platform's headline asset since 2018, is served from a global CDN, and the realistic failure mode is *your token/quota*, not their uptime. Reliability risk to plan for: monthly streaming quota (15 GB on Community) and the plan's non-commercial terms.

**Is it different from what you already have?** Yes, in kind. Your TeaMark decision picked **MapLibre + Atlas** — a 2D/2.5D vector-tile map renderer with a style editor and tile/geocode/elevation APIs. That stack draws maps. Cesium is a *globe* with 3D terrain and 3D Tiles; different layer entirely. The two don't compete for this project because this project doesn't need a map — it needs ground under a 3D house.

**The important part for Dilene.** You do not need CesiumJS to use it. `3d-tiles-renderer` (NASA-AMMOS, MIT) streams Cesium ion terrain *and* Google Photorealistic 3D Tiles straight into a Three.js scene. That's the road to "bay window → neighborhood → DFW" inside the same scene the house lives in, rather than cutting to a map. Ion's Google 3D Tiles asset is `2275207`; usage is metered against your ion quota, not a Google account.

**Verify before relying:** Cesium ion [pricing](https://cesium.com/platform/cesium-ion/pricing/) · [Cesium World Terrain](https://cesium.com/platform/cesium-ion/content/cesium-world-terrain/) · [Google tiles billing via ion (community thread)](https://community.cesium.com/t/google-tiles-api-no-longer-required-how-does-pricing-work/28017). Checked 2026-09-02.

## What you may not have yet

- **Node 22 + npm** locally (`nvm install 22`). Needed to run `npm run dev`.
- **git** configured with your GitHub login (or GitHub Desktop).
- **VS Code** with the JSON Schema validation that comes built in — it will underline mistakes in `floorplan.json` as you type.
- A **Cesium ion** account (free) — only when Milestone 2 starts.
- A **tape measure**. Really. The capture protocol depends on it more than on any app.
